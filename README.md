# BlueMoon: 2021 – VulnHub

## 1. Overview
BlueMoon: 2021 is a beginner-level vulnerable Linux virtual machine created by Kirthik and published on VulnHub. The objective is to perform penetration testing, identify vulnerabilities, gain initial access, escalate privileges, and obtain root access.

## 2. Lab Information
- **Machine:** BlueMoon: 2021
- **Author:** Kirthik
- **Difficulty:** Easy

- **Platform:** VulnHub

- Kali Linux

- Hydra
- FTP and SSH clients

## 5. Lab Objectives
1. Discover the target machine's IP address.
2. Identify open ports and running services.
3. Perform web directory enumeration.
4. Discover and retrieve exposed information.
5. Obtain initial system access.
6. Perform privilege escalation.
7. Obtain root access and capture all flags.

## 6. Methodology
The penetration testing process follows these stages:

- **Reconnaissance:** Discover the target IP address.
- **Enumeration:** Identify open ports, services, and hidden directories.
- **Initial Access:** Investigate exposed information and obtain valid credentials.
- **Privilege Escalation:** Identify misconfigurations and escalate user privileges.
- **Root Access:** Obtain administrative access to the target machine.

## 7. Disclaimer
This virtual machine is intended for educational purposes and authorized penetration testing practice only. Perform all testing within an isolated lab environment. Do not attempt these techniques against systems without permission.
